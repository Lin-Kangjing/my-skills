# 周报生成器

从 git 提交记录自动生成精简的数字排序周报。

## 触发条件

当用户提到以下关键词时触发：
- "周报"、"工作总结"、"汇报进度"
- "总结上周工作"、"做了什么"

## 执行步骤

1. **获取提交记录**：运行 `git log --oneline` 查询指定时间范围的提交，默认为上周（周一到周日）
   - 命令：`git log --oneline --since="<开始日期>" --until="<结束日期>" --author="$(git config user.name)" --all`
   - 如果用户指定了时间范围，使用用户指定的时间
   - 如果未指定，默认取上周（今天是周日则取上周一到上周日）

2. **分类归纳**：按功能模块将提交归类，合并同一功能的多条提交为一个条目
   - feat 类：新功能
   - fix 类：Bug 修复
   - refactor 类：重构优化
   - style/chore/docs 类：辅助性工作（除非是主要工作则单独列出）

3. **生成周报**：输出格式为数字排序的精简列表，每条一句话概括：
   - 格式：`编号. 功能概括（一句话，包含关键改动点）`
   - 不写时间、不写 commit hash
   - 同一功能的多个小改动合并为一条
   - 控制总条目数在 8-12 条之间，太碎的合并，太长的精简
   - 使用中文

4. **如果提交记录为空**：提示用户该时间段内没有提交记录

## 输出格式示例

```
## 周报

1. 独立边（line）从 Node 重构为 Edge，完成拖拽创建、属性面板、端点拖拽、旧数据兼容等全套改造
2. 边标签编辑迭代修复：定位偏移、空文字占位、改为注册时内置
3. 新增图片上传节点，完成组件、注册、拖拽配置
4. 监控模板图标绑定与主机节点图标继承
5. 子拓扑跳转功能：注册隐藏路由、点击跳转、route params 自动选中
6. 搜索组件优化：异步加载补全标签、字符串比较修复预填充
7. 节点锁定保护机制重构，修复子拓扑绑定工具死循环
8. 健康概览样式重构、未匹配组主机数跳转
```

## 注意事项

- 用户可能要求进一步精简或调整格式，根据反馈灵活调整
- 不要过度展开细节，保持每条一句话的原则
- 辅助性提交（style、chore）除非是主要工作内容，否则合并到相关功能条目中
